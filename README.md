# 대치프라임 성적표 시스템 (dcprime-test_repoet)

시험을 직접 만들고, 엑셀 업로드 또는 화면에서 직접 입력으로 명단·성적을 채운 뒤, 학생별 성적표를 JPG로 다운로드하는 내부 도구.

- `dcprime-academy`(dcprime.co.kr)와는 별도 도메인·레포지만, 같은 Supabase 프로젝트(`smnakhjdtbqgwocwlluz`)를 테이블 접두사 `rc_`로 분리해서 공유합니다.
- 마케팅 페이지가 없는 단일 도구로, `src/pages/index.astro` 하나에 시험 관리 + 성적표 다운로드가 모두 들어있습니다. 로그인 게이트는 없습니다 — URL을 아는 사람은 누구나 접근 가능하므로 도메인/링크 노출에 주의하세요.

## 시작하기

```bash
npm install
npm run dev
```

`.env`에 `PUBLIC_SUPABASE_URL`, `PUBLIC_SUPABASE_ANON_KEY`가 필요합니다 (`.env.example` 참고, dcprime-academy와 동일한 값 사용).

## DB 세팅

`supabase-setup.sql`을 Supabase SQL Editor에 붙여넣고 실행하세요 (MCP로 원격 실행 불가, 수동 실행 필요). `CREATE TABLE IF NOT EXISTS` / `ADD COLUMN IF NOT EXISTS` 기반이라 재실행해도 기존 데이터가 지워지지 않습니다.

## 시험 만들기

"시험 관리" 탭에서 시험을 하나씩 만듭니다 — 대상학년(중복 선택 가능), 과목(중복 선택 가능), 시험 이름, 시행 기간(시작일~종료일)을 입력합니다. 대상학년과 과목 모두 여러 개를 고를 수 있어서, 한 시험 하나로 여러 학년·여러 과목을 다 다룰 수 있습니다 (예: "9월 모의고사"에 초5·초6 대상, 국어·영어·수학·과학 다 포함).

## 명단 채우기

시험 목록에서 시험 행을 클릭하면 상세 화면이 열립니다.

- **엑셀 업로드**: 첫 행은 헤더 `학년 | 이름 | 국어 | 영어 | 수학 | 과학` — 과목 컬럼은 필요한 것만 있어도 되고 순서도 상관없습니다. 학생이 안 본 과목은 그 칸을 비워두면 됩니다. `(학년, 과목)` 조합별로 따로 반평균/표준편차/석차를 계산합니다. 같은 학생·과목을 다시 업로드하면 점수가 갱신됩니다.
- **직접 추가**: 학년/과목/이름/점수를 입력해 한 명씩 추가할 수 있습니다.
- **명단 표**에서 각 행의 "수정"으로 점수를 바로 고치거나 "삭제"로 뺄 수 있습니다 — 수정/삭제할 때마다 해당 학년·과목 그룹의 통계가 자동으로 다시 계산됩니다.
- **총평**: 명단 아래에 이 시험 전체에 대한 총평을 적을 수 있고, 성적표 하단에 그대로 표시됩니다.

## 성적표 다운로드

"성적표" 탭에서 시험 → 학년을 선택하면 그 조합에 해당하는 학생 목록이 뜹니다. 학생별 "미리보기" 버튼을 누르면 그 학생이 응시한 모든 과목의 점수·평균·표준편차·예상등급이 한 장의 카드로 나오고(예상등급은 반석차/응시인원을 5등급제 누적 비율 10/34/66/90/100%로 환산), 하단에 총평도 함께 보입니다. 모달 안의 "JPG 다운로드" 버튼으로 이미지를 받습니다.

**전원 JPG 다운로드**: 목록 위의 버튼을 누르면 화면에 뜬 학생 전원의 성적표를 한 명씩 순서대로 생성해서 zip 파일 하나로 묶어 다운로드합니다 (진행 상황이 버튼 옆에 표시됨). 카카오톡 전송은 개별이든 전체든 수동으로 진행합니다.
