# 대치프라임 성적표 시스템 (dcprime-test_repoet)

시험을 직접 만들고, 엑셀 업로드 또는 화면에서 직접 입력으로 명단·성적을 채운 뒤, 학생별 성적표를 JPG로 다운로드하는 내부 도구.

- `dcprime-academy`(dcprime.co.kr)와는 별도 도메인·레포지만, 같은 Supabase 프로젝트(`smnakhjdtbqgwocwlluz`)를 테이블 접두사 `rc_`로 분리해서 공유합니다.
- 마케팅 페이지가 없는 단일 도구로, `src/pages/index.astro` 하나에 시험 관리 + 성적표 다운로드가 모두 들어있습니다. 로그인 게이트는 없습니다 — URL을 아는 사람은 누구나 접근 가능하므로 도메인/링크 노출에 주의하세요.

## 시작하기

```bash
npm install
npm run dev
```

`.env`에 `PUBLIC_SUPABASE_URL`, `PUBLIC_SUPABASE_ANON_KEY`가 필요합니다 (`.env.example` 참고, dcprime-academy와 동일한 값 사용).

## DB 세팅

`supabase-setup.sql`을 Supabase SQL Editor에 붙여넣고 실행하세요 (MCP로 원격 실행 불가, 수동 실행 필요). ⚠️ 재실행하면 `rc_exams`/`rc_scores` 데이터가 전부 삭제되고 새로 만들어집니다(스키마가 바뀔 때만 재실행).

## 시험 만들기

"시험 관리" 탭에서 시험을 하나씩 만듭니다 — 대상학년(중복 선택), 과목(국어/영어/수학/과학 중 하나), 시험 이름, 시행 기간(시작일~종료일)을 입력합니다. **과목은 시험 하나당 하나**이므로, 한 시험 기간에 여러 과목을 볼 경우 같은 시험 이름으로 과목별 시험을 각각 만드세요 (예: "9월 모의고사"-국어, "9월 모의고사"-수학). 성적표 탭에서는 같은 시험 이름을 가진 시험들이 자동으로 묶여서 한 학생의 여러 과목 성적이 한 장의 성적표로 나옵니다.

## 명단 채우기

시험 목록에서 시험 행을 클릭하면 상세 화면이 열립니다.

- **엑셀 업로드**: 컬럼 순서(헤더 행 1줄 포함) `학년 | 이름 | 점수`. 대상학년이 여러 개인 시험이면 엑셀에 여러 학년의 학생이 섞여 있어도 됩니다 — 학년별로 따로 반평균/표준편차/석차를 계산합니다. 같은 학생을 다시 업로드하면 점수가 갱신됩니다.
- **직접 추가**: 학년/이름/점수를 입력해 한 명씩 추가할 수 있습니다.
- **명단 표**에서 각 행의 "수정"으로 점수를 바로 고치거나 "삭제"로 뺄 수 있습니다 — 수정/삭제할 때마다 해당 학년 그룹의 통계가 자동으로 다시 계산됩니다.

## 성적표 다운로드

"성적표" 탭에서 시험 이름 → 학년을 선택하면 그 조합에 해당하는 학생 목록이 뜹니다. 학생별 "미리보기" 버튼을 누르면 같은 시험 이름을 가진 모든 과목의 성적이 한 장의 카드로 합쳐져 보이고, 모달 안의 "JPG 다운로드" 버튼으로 이미지를 받습니다. 카카오톡 전송은 수동으로 진행합니다.
